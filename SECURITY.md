# Security Policy

## Supported Versions

Security fixes and vulnerability reports are currently accepted for the latest version available on the `main` branch.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately through GitHub's private vulnerability reporting feature, if enabled.

Do not disclose vulnerabilities publicly in GitHub Issues before the maintainers have had an opportunity to investigate.

When reporting a vulnerability, please include:

- A description of the potential vulnerability.
- Steps to reproduce the issue.
- The possible impact.
- Relevant logs or evidence, with passwords, tokens, and other sensitive information removed.

The maintainers will review the report and determine the appropriate next steps.

## Scope

This policy applies to the code and configuration maintained in this repository.
